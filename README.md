📊 Student Feedback Analysis Project

This project was completed as part of my internship with [Future Interns]. The goal was to analyze student event feedback, uncover satisfaction trends, and suggest improvements for future events.

🔎 Project Overview

✅ Cleaned and prepared survey data (exported from Google Forms)

✅ Normalized student ratings to a 1–5 scale for consistency

✅ Performed NLP sentiment analysis on text feedback (positive / neutral / negative)

✅ Created visualizations to identify trends and insights

✅ Suggested improvements based on lowest-rated aspects and sentiment patterns

📊 Visualizations Included

Distribution charts → Showed how students rated each aspect of the event

Average rating bar chart → Compared ratings across categories (e.g., presentations, assignments, subject expertise)

Correlation heatmap → Identified relationships between feedback categories

Sentiment analysis plots → Displayed proportions of positive, neutral, and negative feedback

Improvement insights → Highlighted lowest-rated areas (e.g., difficulty of assignments, use of presentations) with recommendations

🛠️ Tools & Libraries

Python (Google Colab)

Pandas, NumPy → Data cleaning & preparation

Matplotlib → Data visualization

NLTK / TextBlob → Sentiment analysis

Google Colab → Development environment

🚀 Key Learnings

Handling real-world survey data and preparing it for analysis

Applying sentiment analysis to textual student feedback

Deriving actionable insights from both quantitative ratings and qualitative comments

Presenting findings through clear and insightful visualizations
